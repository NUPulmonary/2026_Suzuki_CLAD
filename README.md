# 2026_Suzuki_CLAD
Interstitial macrophages drive chronic lung allograft dysfunction


BIORXIV LINK!

This repository contains analysis code for this study. Please, direct any questions to the corresponding authors of the study, or feel free to open an issue in this repository.

The code was run with Python 3.9, 3 virtual environments were used for clustering (R/4.2.3), niche calculation (cellcharter-env), and figure generation (figure_env). Clustering code was ran with R/4.2.3, managed via rlock. Niche calculation and figure was ran with Python 3.11, managed via pip-tools. 





00_Mouse_Xenium: cleaning, processing, analysis, and figures related to mouse Xenium data.

01_Human_Xenium: cleaning, processing, analysis, and figures related to human Xenium data.

02_Human_scRNA-seq: analysis and figurers related to human scRNA-seq data.
